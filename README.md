# java-racingcar-precourse
## 기능 목록
### 1. 입력 (Input)

- [x] 경주할 자동차 이름 입력 받기

- [x] 시도할 횟수 입력 받기

- [x] 입력값 유효성 검사
    - [x] 시도할 횟수가 1 미만의 숫자인 경우 `IllegalArgumentException` 발생
    - [x] 예외 발생 시 애플리케이션 종료



### 2. 차생성
- [ ] 입력받은 이름으로 자동차 객체 목록 생성
  - [ ] 각 자동차는 이름과 현재 위치(거리) 정보를 가진다.
  - [ ] 이름은 쉼표(,)를 기준으로 구분한다.
  - [ ] 자동차 이름이 5자를 초과하는 경우 `IllegalArgumentException` 발생


### 3. 경주 (Race)

- [ ] 각 차수(라운드)별 레이스 진행
    - [ ] 0에서 9 사이의 무작위 값을 구한다.
    - [ ] 무작위 값이 4 이상일 경우 전진(위치 1 증가)한다.
    - [ ] 4 미만일 경우 멈춘다.

- [ ] 우승자 판별
    - [ ] 가장 멀리 전진한 자동차를 찾는다.
    - [ ] 우승자는 한 명 이상일 수 있다.


### 4. 출력 (Output)

- [ ] 차수별 실행 결과 출력
    - [ ] 입력된 시도 횟수만큼 반복
    - [ ] 매 라운드 종료 시, 각 자동차의 현재 위치 출력 (예: `pobi : --`)

- [ ] 최종 우승자 안내 문구 출력
    - [ ] 단독 우승자인 경우 (예: `최종 우승자 : pobi`)
    - [ ] 공동 우승자인 경우 쉼표(,)로 구분 (예: `최종 우승자 : pobi, jun`)
